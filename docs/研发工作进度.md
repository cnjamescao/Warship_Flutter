## 七、本轮建立的**诊断与守卫**（长期资产）

这些是把「**静态检查通过 ≠ 画面正确**」这个反复踩坑处交给机器把守的机制：

| 机制 | 作用 |
| --- | --- |
| `drawnAssetMaxRadius` + 累积绘制历史 | 运行时上报"这一帧实际画了哪些资源、画了多大"，落盘到沙盒可写目录 |
| 预警几何上报 | 输出 `len` / `band` / `rot` / 素材尺寸，用于定性"画出来是什么" |
| **绘制记录覆盖度守卫** | 断言每处 `drawImageRect` 都进记录，防止盲区复发（我为此踩过三次） |
| 实体外观 vs 事件视觉守卫 | 防止"事件资源顶替实体外观"（F-28 / F-31 同类） |
| 重复素材守卫 | 按**文件内容**比对，冻结重复规模 |
| 素材溯源守卫 | 源稿 → 运行时 → 应用侧逐环哈希校验 |
