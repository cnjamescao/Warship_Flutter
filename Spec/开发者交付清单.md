## 3. 不可突破的交付边界

- 不修改产品、技术、素材文件规定以外的数值、状态机、文本、Asset ID 或 cue。
- 不用占位图、通用 beep、Canvas 几何或旧 v2.0 图替代 v2.1 正式资源。
- 不保留用户可进入的三选一 Draft 路径；风险门除外。
- 不让 App 层通过生命值或 190 秒倒数自行推断胜负；只消费 Runtime 的 RunEnded。
- 所有新增 public API、事件和时序取消逻辑须有中文业务注释。
- 每个批次完成后先通过对应自动化和 Golden，再进入下一批；测试不得写回 fixture。

## 4. 当前状态

**可立即开工。** 唯一不影响开发的后续门禁是发布前的新增音频试听/响度/并发签收，以及 Release/Web/设备人工验收。历史 v2.0 文档与 Spec/99_历史归档 只可追溯，不能作为 v2.1 实现依据。
