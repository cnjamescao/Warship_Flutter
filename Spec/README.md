# Warship v2.0 开发资料总入口

> **开发入口：** 新增或修改 v2.0 功能时，只使用本页列出的“生效资料”。`99_历史归档/` 仅用于追溯，不能作为实现、验收或资源加载依据。

## 一线研发阅读顺序

1. [产品研发交付基线](01_产品/Warship_v2.0研发交付基线.md)：首发范围、精确数值、内容 ID 与产品验收基线。
2. [现代化产品设计文档](01_产品/Warship现代化产品设计文档.md)：交互、体验、界面、无障碍与音画状态要求。
3. [技术设计包](02_技术/v2.0/README.md)：模块架构、数据/事件协议、实施工作包与验收测试。
4. [素材清单与制作规范](03_素材/Warship_v2.0素材清单与制作规范.md)：唯一生效的 Asset ID、状态、路由、格式和资源验收规则。
5. [正式素材包](../素材/README.md)：实际可加载的 manifest、运行时图形、运行时音频、源文件和校验工具。

## 资料与权威范围

| 范围 | 唯一生效位置 | 使用规则 |
| --- | --- | --- |
| 产品范围、数值、内容 ID | `01_产品/Warship_v2.0研发交付基线.md` | 与其他文档冲突时，以此为准。 |
| 交互、UI、音画和体验 | `01_产品/Warship现代化产品设计文档.md` | 不得覆盖产品基线中的数值或范围。 |
| 工程架构、运行时协议、开发顺序、测试 | `02_技术/v2.0/` | 实现前先阅读完整技术设计包。 |
| 素材规范、Asset ID、事件路由 | `03_素材/Warship_v2.0素材清单与制作规范.md` | 所有资源只能按此规范和 manifest 接入。 |
| 实际发布资源 | `../素材/manifest.json` | 当前内容版本为 `2.0.6-material-repair`（已包含 v2.0.7 审计补丁）；禁止硬编码资源路径或另建资源清单。 |

> **资源目录边界：** 根目录 `素材/` 是 v2.0 唯一正式资源包；根目录 `assets/images/` 与 `assets/audio/` 是升级前 Flutter 基线仍在使用的旧资源，只用于保持当前基线可运行和迁移对照。v2.0 实现必须按技术协议将 `素材/manifest.json` 及其运行时文件构建复制到应用资源目录，不能直接复用旧资源替代正式 Asset ID。

## 当前阶段与验收结论

阶段一的 v2.0 实现、自动化和 Release 构建已完成收口；当前处于**QA / 素材 / 人工验收收尾**，不是正式发布通过。开始下一版本工作前，先阅读 [docs/README.md](../docs/README.md) 的现行状态、需求变更与验收入口；新增需求必须从产品基线开始更新，不能直接在旧过程文档上继续追加。

`99_历史归档/` 及 `docs/99_历史归档/` 包含 v1.x 文档、旧素材清单、阶段一过程稿、旧台账和历史代码审查记录，均只可追溯，不是实现依据。
