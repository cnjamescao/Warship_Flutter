## 版本与变更标识

- **[保留 v2.0]**：离线无登录、风险门选择、敌人波次、Boss 招式、基础数值和 v2.0 未列项；只作为新版本继承基线。
- **[变更 v2.1]**：手动三选一改自动强化且不冻结；清场确认即时胜利；顶部倒数改目标提示；主弹道形态随机惊喜；三档独立奖章与短促动效。
- **[新增 v2.1]**：五种主弹道、AutoUpgradeGranted/SectorClear 事件、清场状态、非阻断 Toast、逐帧状态动效、21 图形/UI Asset ID 与 12 条音频 cue。
- **[归档]**：仅用作历史事实和裁决追溯，不能作为实现、资源加载、测试或验收依据。

## 目录与归档规则

- Spec/01_产品/v2.1、Spec/02_技术/v2.1、Spec/03_素材/v2.1 和根目录 素材/v2.1 是当前唯一 v2.1 开发资料。
- v2.0 版本文件是已实现基线的历史资料，不能覆盖 v2.1。
- Spec/04_下一版本规划 已完成 v2.1 的提案职责；原始过程稿见 Spec/99_历史归档/版本决策/v2.1_冻结过程。
- Spec/99_历史归档 中的资料不能作为运行时或开发输入。

## 当前可开工与发布前边界

v2.1 所需产品、技术、测试、真实图形及可解码音频均已交付，研发可以直接开工。发布前仍需音效师对 12 条新增 WAV 完成试听、响度和并发签收，并按技术测试计划完成 Release、Web 和真实设备验收；这是发布 QA 门禁，不是研发实施前的产品或架构待确认项。
