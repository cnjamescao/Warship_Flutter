# v2.1 产品功能说明

> 状态：**当前生效 v2.1 产品功能说明。** [变更 v2.1] 内容已完成技术、素材和测试交叉设计；研发按 `Spec/02_技术/v2.1/` 实施，不再等待二次确认。

## 1. 玩家流程变化

`开局 → 持续战斗 → 自动强化/自动风险结算的结果徽记（不中断） → Boss/清场确认 → 结果奖章`。

- 强化阈值与风险门触发后都不进入选卡/选择界面；系统确定性抽取一项合法结果并即时应用。
- 游戏内只显示高可见度的无文字结果徽记，不显示包裹文字的框、说明卡或确认按钮；徽记不拦截移动、射击、冲刺或暂停。
- 未来无计划威胁且场上敌人/敌弹/危险区/待攻击均为零时，显示 0.8 秒“扇区已清空”，随即结算。
- Gold/Silver/Bronze 规则不变，但奖章的形状、动效和声音必须不同。

## 2. 具体交互与表现合同

### 2.1 自动强化

1. 达到强化阈值的同一逻辑帧，系统依据本局 seed 从当前合法池抽取且只抽取一项；不得出现重新抽取、三选一、或等待玩家确认。
2. 授予后立即改变战斗能力。首次获得「主弹道形态」时，随机结果为 Prism、Arc、Plasma、Needle、Missile 之一；这是惊喜型强化的一部分，不是开局职业选择。
3. 右上安全区显示 1.0 秒无文字结果徽记：弹出 90ms、可读停留 580ms、收束淡出 330ms；不显示框、文字、等级或说明。任何时刻均不吸收触摸、鼠标或键盘输入；无障碍服务使用本地化语义标签朗读结果。
4. 结算页展示本局强化历史，供玩家理解“这局为何变强”；该历史不需要账号、登录或云端保存。

### 2.1A 自动风险结算【新增 v2.1-R2 / P0】

风险门不再是玩家选择点。`RG-55`、`RG-115` 到达时，战斗保持 `Playing`，从合法的 Supply / Bounty / Overload 结果等权随机一项并立即执行。补给显示绿色补给徽记，悬赏显示琥珀悬赏徽记，超载显示洋红反应堆徽记；强化显示青色棱晶徽记。每种徽记均是独立视觉轮廓而非换色矩形。结果的中文名称、具体数值和代价只记录在暂停页、结算页和无障碍语义中，不在战斗中要求玩家阅读。

### 2.2 清场立即结算

1. “所有计划威胁完成”指 Director 不再有未来威胁或 Boss 入场计划；“战场清空”指敌机、敌方投射物、危险区及待执行攻击均为零。
2. 四条件同时满足后进入 0.8 秒确认窗，显示低干扰的“扇区已清空”提示；确认窗内若出现任一新威胁，必须取消，不能结算。
3. 确认窗结束立即进入既有结果流程，不再为了顶部剩余数字或总时长让玩家空等；Boss HP 归零的既有胜利优先级保持更高。

### 2.3 动效与奖章

- 所有状态表现均遵循“出现 → 峰值 → 收束”，不能是一张静态图覆盖数秒。护盾受击使用四帧序列；HP 受击、低血、濒危、击毁与 HUD 提示使用真实图形加规定的时间曲线，不得用色块、空图或同图替代。
- 视觉基调：霓虹硬科幻、利落短促；单次爆发通常不超过 600ms，持续告警采用低频脉冲且不得遮挡机体、危险区或操作。
- Gold 为翼状六角星章、Silver 为圆盾月弧章、Bronze 为三角反应堆章；除形状外，各自使用不同入场节奏和确认音。奖牌判定规则不变。

## 3. 功能验收标准

| 功能 | 玩家可见通过条件 |
| --- | --- |
| 自动强化 / 自动风险结算 | 不停手、不遮挡战场；无卡片/文字框/三选一；能看到独立结果徽记和战机/弹道变化；暂停或结算可回看完整历史 |
| 弹道形态 | Prism/Arc/Plasma/Needle/Missile 任一出现时，弹体、尾迹/命中和至少一个规则参数可区分 |
| 状态动效 | 护盾/HP 受击、低血、濒危、击毁都有出现—峰值—收束；机体与危险区不被遮挡 |
| 清场结算 | 没有可交互威胁时不会继续空等倒计时 |
| 三档奖章 | 不读文字也可通过外形区分，且有短促入场动效和不同确认音 |

## 4. 功能点、优先级与交付依赖

| 功能点 | 优先级 | 玩家价值 | 必须依赖 | 对应验收 |
| --- | --- | --- | --- | --- |
| 自动强化与自动风险结算 | P0 | 消除所有玩法选择打断 | 确定性抽取、无文字结果徽记、历史记录 | V21-AU-01/02、V21-RISK-01~04、Golden |
| 清场立即胜利 | P0 | 消除无敌可打时的空等 | 完整 ThreatSnapshot、0.8s 取消逻辑 | V21-CLEAR-01/02、Release 录屏 |
| 五种随机主弹道 | P1 | 每局有意外与可识别变化 | 独立投射物、命中图、cue、seed | V21-STYLE-01、Golden |
| 状态动效 | P1 | 让战斗反馈现代、可读 | 图形 sheet、表现时钟、并发限制 | V21-FX-01/02、Golden |
| 三档动效奖章 | P1 | 让结算有明确成就感 | 三形状、三 cue、既有判定 | V21-MEDAL-01、Golden |

P0 必须先于 P1；所有功能最终均经过素材、代码审查和 Release 验收，具体批次门禁见 [实施工作包与交付标准](../../02_技术/v2.1/03_实施工作包与交付标准.md)。

自动强化的确切授予序号、五形态首发参数、HUD 目标文案与动效尺寸/时序，以本目录的 [功能冻结表](Warship_v2.1功能冻结表.md) 为最终执行口径。
