## 执行分层与证据

| 层级 | 用例 | 必须证据 | 禁止替代 |
| --- | --- | --- | --- |
| Domain 单元 | AU、CLEAR、STYLE | 固定 seed 的快照、事件顺序、取消分支 | 不能以 Widget 测试替代确定性断言 |
| 表现/Widget | FX、MEDAL | 在 `t=0/峰值/结束` 的三张 Golden、输入仍穿透 | 不能以“组件存在”替代真实动效变化 |
| 素材 | ASSET-01/02 | 解码/hash 检查加逐图核看/逐条试听签署 | 不能只验文件名、大小或 hash |
| Release | GOLDEN、人工回归 | macOS 与 Web 的录屏、真实音频手势验证 | 不能以 debug 截图或脚本伪造录屏替代 |
| 代码评审 | CR-01 | 注释、命名、所有权、资源 ID 路由、测试隔离记录 | 不能以 `analyze` 通过替代评审 |
| Web 自动化 | WEB-T-01～06 | WASM 产物、适配器测试、视口/生命周期/音频降级、静态托管探测 | 不能以“Web 能打开”替代平台行为验收 |
| 双端 RC | DUAL-T-01～03 | 同 commit 的 macOS/Web 构建、hash、release-manifest、两端 Release 证据 | 不能分别发布或以不同内容版本拼成同一 RC |

## v2.1-R2 专项 Golden 与静态负向检查

1. 新增四张 Golden：`auto_upgrade_emblem`、`risk_supply_emblem`、`risk_bounty_emblem`、`risk_overload_emblem`。每张只允许呈现指定真实帧，均需人工看图确认无文字、框、卡片或占位图；相邻两张不得像素完全相同。
2. 生产目录静态检查：禁止在对局路径出现 `_DraftOverlay`、`_RiskGateOverlay`、`selectDraftCard`、`selectRisk`、`DraftOffer` 或 `RiskGateView` 的可达调用；禁止结果徽记 Widget 包含可见 `Text`、`Button`、`InkWell`、`GestureDetector` 或非透明背景装饰。
3. 资源完整性检查：四个新 Asset ID 共用的 sheet 必须具有相同 SHA/runtimeFile，四个 `frameRect` 互不重叠、并集不越界；构建产物中物理 PNG 仅一份。禁止 basename 扁平化导致覆盖，也禁止复制四份同图。
4. 回放 fixture 一律只读。正常 `flutter test` 后 `git diff -- test/fixtures/replays/` 必须为空；仅 `--dart-define=UPDATE_REPLAY_BASELINE=1` 可重建，且必须输出原因、旧/新 SHA-256 与变更摘要到 `build/reports/replay/`。
5. AC-06 不得被放宽：20 个固定 seed、零移动/零冲刺/零暂停输入跑至 180s，必须 `0/20 victory`；实现以内容平衡调整达标，并在报告中提交最终配置 SHA 与 20 条结果。该项仍需最后人工复验，不能以脚本代替新手 60 秒和无伤通关验收。
6. `V21-AUDIO-01/02` 必须在 macOS 与 Web Release 各人工试听一次：连续盾击、连续 HP 击、Boss 连续命中、普通敌人连续命中与 BGM 同播。自动化路由测试不能替代试听；试听需记录是否有双声、漏声、削波或 Boss 命中被掩盖。
