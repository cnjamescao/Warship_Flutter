# v2.1 素材包索引

本目录是**未接入 v2.0 的 v2.1 开发输入**。资源编号、裁切坐标、hash 与验收状态以 [v2.1 素材清单、帧表与接入说明](../08_v2.1素材清单与接入说明.md) 为唯一准则。

```text
素材/
├── 图形/
│   ├── 动效序列/        护盾、状态效果、非阻断 HUD 提示
│   ├── 武器形态/        五种弹道与五种独立命中特效
│   └── 奖章/            Gold / Silver / Bronze 结果奖章
└── 音频/
    └── 运行时WAV/       状态、强化、清场、奖章与五种命中 cue
```

接入前必须核验 Asset ID、文件 hash 和 frameRect；不得按目录顺序、文件名猜测，或将素材复制进 v2.0 的运行时目录。图形可以进行 manifest 接入准备；音频仍待音效师试听与响度签收。
