# v2.1 测试与验收用例

> 测试必须与 [09_v2.1一线实施冻结表](09_v2.1一线实施冻结表.md) 的固定数值和 [10_v2.1代码改造蓝图](10_v2.1代码改造蓝图.md) 的实际改造入口同时对照；不得因旧 Draft、旧 190 秒胜利或静态占位渲染仍能通过而放行。

| V21-ASSET-02 | 全部 v2.1 音频素材 | 文件可播放；音效师逐条试听、响度与并发试听签署；cue 与文件一一对应 |

发布前还需在 macOS/Web Release 实测音效、动画、清场无空等，并留存录屏。

## 执行分层与证据

| 层级 | 用例 | 必须证据 | 禁止替代 |
| --- | --- | --- | --- |
| Domain 单元 | AU、CLEAR、STYLE | 固定 seed 的快照、事件顺序、取消分支 | 不能以 Widget 测试替代确定性断言 |
| 表现/Widget | FX、MEDAL | 在 `t=0/峰值/结束` 的三张 Golden、输入仍穿透 | 不能以“组件存在”替代真实动效变化 |
| 素材 | ASSET-01/02 | 解码/hash 检查加逐图核看/逐条试听签署 | 不能只验文件名、大小或 hash |
| Release | GOLDEN、人工回归 | macOS 与 Web 的录屏、真实音频手势验证 | 不能以 debug 截图或脚本伪造录屏替代 |
| 代码评审 | CR-01 | 注释、命名、所有权、资源 ID 路由、测试隔离记录 | 不能以 `analyze` 通过替代评审 |
