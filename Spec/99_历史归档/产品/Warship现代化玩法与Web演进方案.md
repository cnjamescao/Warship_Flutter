# Warship 现代化玩法与 Web 演进方案

> **创意参考提示（2026-10-12）**：本文保留现代化玩法的创意来源，其中部分候选内容（竖屏、手柄、额外武器等）未进入 v2.0。它不具有实现约束力；唯一生效的产品和数值规范为 [Warship_v2.0研发交付基线.md](../../01_产品/Warship_v2.0研发交付基线.md)。

> 版本：v0.1（创意与产品方向）
>
> 基础：当前 Flutter + Flame 单机版
>
> 目标：升级为一款三分钟内随时可玩、容易上手、不易精通、愿意“再来一局”的现代轻量太空射击游戏。

## 1. 产品愿景

### 一句话定义

Warship: Neon Last Stand 是一款“生存割草 + 弹幕闪避 + 局内构筑”的太空射击游戏。

玩家只需移动、射击和释放一个技能，却能在敌群组合、三选一升级、精英战和风险奖励间持续做决定。每一局应产生这个情绪循环：

> 惊险躲开 → 拿到强力升级 → 火力爆炸 → 再撑十秒

### 设计原则

| 原则 | 解释 |
| --- | --- |
| 3 秒懂 | 打开即玩，移动、击杀和升级无需教程。 |
| 30 秒爽 | 前 30 秒必须有首次强击杀反馈和第一次升级。 |
| 3 分钟完整 | 有开局、中段构筑、终局高潮和明确结算。 |
| 低输入、高决策 | 操作少；选什么升级、何时冲刺、追不追奖励影响胜负。 |
| 强反馈 | 射击、击杀、受伤、升级都要有清晰的画面和音效反馈。 |
| 无账号、可离线 | 不登录、不联网、不阻断；数据仅保存在本地。 |

## 2. 现状与目标

当前项目已有稳定的游戏循环、固定逻辑画布、输入、暂停、音效、测试和状态管理。这是很好的基础。

| 当前限制 | 升级方向 |
| --- | --- |
| 敌人同质、整齐横移 | 多行为敌人 + 组合式波次。 |
| 只有左右移动和单一射击 | 自动射击、Dash、主动技能。 |
| 难度只有越来越快 | 通过敌人组合、弹幕、精英词缀创造压力。 |
| 分数是唯一动力 | 局内构筑、风险门、战绩卡和本地纪录。 |
| UI 偏功能性 | 深空霓虹视觉、清晰信息层级和轻动效。 |

~~~mermaid
flowchart LR
    A[0–10秒<br/>立即射击与击杀] --> B[10–30秒<br/>敌人组合出现]
    B --> C[30–45秒<br/>第一次三选一升级]
    C --> D[45–120秒<br/>构筑 + 精英敌人]
    D --> E[120–165秒<br/>风险奖励]
    E --> F[165–180秒<br/>Boss/撤离结算]
    F --> G[一键再来一局]
~~~

## 3. 单局核心循环

~~~mermaid
flowchart TD
    A[开始一局] --> B[移动、自动/手动射击]
    B --> C[击毁敌人，获得能量晶体]
    C --> D{经验条满？}
    D -- 是 --> E[时间短暂停止<br/>三选一升级]
    E --> B
    D -- 否 --> F{精英或风险门？}
    F -- 是 --> G[安全绕开或高风险高奖励]
    G --> B
    F -- 否 --> B
    B --> H{180秒到 / Boss击败？}
    H -- 是 --> I[战绩结算]
    H -- 否 --> J{生命耗尽？}
    J -- 否 --> B
    J -- 是 --> I
~~~

### 输入

| 平台 | 移动 | 主攻击 | 技能 |
| --- | --- | --- | --- |
| macOS / 桌面 Web | WASD 或方向键 | 默认自动射击；空格集火或手动射击 | Shift 或右键 |
| 触摸 Web（未来） | 左半屏拖拽 | 默认自动射击 | 右下大按钮 |
| 手柄（未来） | 左摇杆 | 自动瞄准或右摇杆 | 肩键 |

建议默认自动射击，以降低首次门槛。空格不必只是“发一颗子弹”，可以变为集火、蓄力或短时间过载，给熟练玩家更高上限。

## 4. 敌人与导演式波次

不要只提高速度。每个敌人只引入一个容易理解的行为；不同组合自然产生策略。

| 敌人 | 行为 | 玩家应对 |
| --- | --- | --- |
| 侦察机 | 快速俯冲，生命低 | 快速清理，持续移动 |
| 护卫舰 | 正面护盾，侧后脆弱 | 横移绕侧或使用穿透 |
| 分裂体 | 击毁后分裂为小体 | 范围武器更有效 |
| 爆破虫 | 靠近自爆，留下危险区 | 优先击杀或 Dash 穿过 |
| 狙击舰 | 预警线后发射直线弹 | 看线躲避 |
| 采集者 | 缓慢逃跑，掉大量资源 | 决定是否追击 |
| 精英变体 | 护盾、加速、分裂或弹幕词缀 | 高风险、高回报 |

| 时间 | 节奏 | 示例 |
| --- | --- | --- |
| 0–30 秒 | 教学式低压 | 侦察机 + 少量护卫舰 |
| 30–75 秒 | 建立构筑 | 分裂体 + 第一只精英 |
| 75–130 秒 | 位置挑战 | 爆破虫 + 狙击预警 |
| 130–165 秒 | 高压选择 | 采集者、精英、风险门 |
| 165–180 秒 | 高潮 | 小 Boss 或最终舰队 |

当玩家只剩一条命时，系统应降低同时出现的高压单位数量，但不能完全放水；目标是“险胜可能”，不是“必死”。

## 5. 武器、子弹与技能

### 初始武器：从黑色矩形升级为激光

- 青蓝色短激光：白色核心、彩色外发光、轻拖尾；
- 炮口有 80–120ms 的闪光，命中敌人闪白并飞出碎片；
- 每 6–8 发出现一次更亮的脉冲弹；
- 射击音有细微音高变化，避免机械重复；
- 子弹、粒子、伤害数字必须对象池复用。

### 局内武器升级

每次升级给三选一。升级池应优先提供与玩家当前构筑协同的项目，避免三个无意义选项。

| 武器/模块 | 初始效果 | 后续成长 |
| --- | --- | --- |
| 双联激光 | 两道平行激光 | 扇形、额外炮管 |
| 追踪导弹 | 追踪最近精英 | 多弹头、爆炸范围 |
| 等离子散射 | 近距离扇形子弹 | 穿透、反弹 |
| 电弧线圈 | 自动电击附近目标 | 链数、范围、暴击 |
| 轨道无人机 | 环绕飞船射击 | 数量、转速、护盾 |
| 穿透棱镜 | 激光贯穿敌人 | 折射、暴击、分裂 |
| 黑洞雷 | 吸附敌人的冷却技能 | 范围、持续、爆炸 |

### 主动技能

首版建议先做相位冲刺：

- 短距离 Dash；
- 0.35 秒无敌；
- 穿过敌人时留电弧；
- 20 秒左右冷却；
- 键盘 Shift，触摸端右下角大按钮。

它直接让躲弹从被动变主动，是最小成本、最高价值的操作升级。

## 6. 奖励、惩罚与公平

| 层级 | 获得方式 | 回报 |
| --- | --- | --- |
| 即时 | 击杀、连杀、命中 | 爆炸、晶体、音效、分数 |
| 局内 | 升级、精英、风险门 | 武器强化、技能充能、宝箱 |
| 局外 | 单局结算 | 本地最高分、战绩卡、外观或起始模块 |

### 风险门

每 45–60 秒出现一个可绕开的裂隙门：

| 门 | 风险 | 奖励 |
| --- | --- | --- |
| 过载门 | 15 秒敌人加速 | 立即一次升级 |
| 玻璃大炮 | 最大生命 -1 | 伤害 +35% |
| 富矿门 | 出现精英守卫 | 大量晶体 + 宝箱 |
| 不稳定门 | 边缘暂时收缩 | 稀有升级重掷 |

公平规则：

1. 风险必须可见、描述极短、可选择；
2. 不做无预警秒杀；
3. 受伤后给 2 秒无敌和明显边缘提示，避免连续死亡；
4. 最后一条命时不把风险门放在必经路线。

生命建议改为三格装甲芯。击败精英有机会掉落修复芯片；这能产生小型逆转，但不让治疗泛滥。

## 7. 现代 UI 与视觉

### Neon Tactical 风格

| 元素 | 建议 |
| --- | --- |
| 背景 | 深蓝黑渐变、慢速星云、少量星点 |
| 主色 | 电光青 #56E8FF |
| 危险 | 珊瑚红 #FF5E6C |
| 奖励 | 琥珀金 #FFC857 |
| 稀有 | 紫罗兰 #B47CFF |
| 面板 | 半透明深色玻璃、细描边、轻微模糊 |
| 字体 | 数字科技感；中文保持系统无衬线清晰度 |

### HUD 草图

~~~text
┌──────────────────────────────────────────────────────────┐
│  ♥ ♥ ♥        SCORE 12,450              [⏸] [🔊]         │
│  Lv. 6  ████████████░░░  72%             02:14           │
│                                                          │
│                 战斗世界                                 │
│                                                          │
│  [Dash ready]                   COMBO ×12                │
└──────────────────────────────────────────────────────────┘
~~~

只保留三类常驻信息：生存、成长、结算目标。连杀、精英预警和升级是短暂信息，不要长期堆在屏幕上。

关键动效：开火闪光、命中碎片、击杀晶体吸附、升级卡片滑入、受伤短震屏、Boss 横幅。设置中应有减少震动、减少闪烁和高对比选项。

结算页应展示分数、存活时间、最高连杀、精英击杀、局内构筑图标和一句动态战报；再来一局必须是最大、默认聚焦的按钮。

## 8. 三分钟节奏

| 时间 | 体验 |
| --- | --- |
| 0:00 | 自动开火、低压敌人 |
| 0:15 | 首次连杀/小强化 |
| 0:30 | 第一次三选一 |
| 0:45 | 第一只精英 |
| 1:10 | 第二次升级，构筑差异明显 |
| 1:30 | 风险门或高价值采集者 |
| 2:00 | 敌人组合与弹幕压力 |
| 2:30 | 稀有升级或技能满充能 |
| 2:45 | Boss/撤离预告 |
| 3:00 | 结算与立即重开 |

## 9. Web 版本演进

目标是静态网页：打开链接即可玩，无账号、无服务端、无实时通信。

~~~mermaid
flowchart LR
    A[Flutter / Flame 游戏核心] --> B[macOS App]
    A --> C[Flutter Web]
    C --> D[静态构建文件]
    D --> E[GitHub Pages / Cloudflare Pages / Netlify / Vercel]
    E --> F[浏览器直接游玩]
    F --> G[localStorage<br/>设置与本地最高分]
~~~

| 领域 | Web 要求 |
| --- | --- |
| 规则 | 继续保持纯 Dart，不引用 macOS API |
| 输入 | 新增 Pointer/Touch 输入适配层 |
| 音频 | 首次点击 Play 后启用，符合浏览器手势策略 |
| 存储 | 定义 LocalProgressStore；Web 使用 localStorage，App 使用本地偏好存储 |
| 生命周期 | 页面隐藏或失焦自动暂停，回来仍保持暂停 |
| 视口 | 保留 800×600 logical world，Web 响应式缩放 |
| 性能 | 对象池、粒子上限、低性能模式 |

Web 细节：

1. 阻止空格滚页、拖拽选中文字和触摸滚动影响游戏区域；
2. 触摸端默认自动射击，左侧拖动移动、右下 Dash；
3. 使用 flutter build web --release 产物部署静态托管；
4. CI 增加 Web release build，保证每次提交可部署；
5. 可先部署到 Cloudflare Pages 或 Netlify，后续接自有域名。

## 10. 技术改造

建议新增以下领域模块：

~~~text
lib/game/
  director/      波次导演、难度曲线
  combat/        武器、伤害、投射物对象池、主动技能
  progression/   经验、升级目录、三选一、LocalProgressStore
  presentation/  游戏主题、粒子管理、Web 触屏控制层
~~~

升级、敌人和波次应数据驱动：

~~~text
UpgradeDefinition: id, rarity, tags, description, prerequisites, apply()
EnemyDefinition: id, hp, speed, behavior, dropTable, telegraphStyle
WaveRecipe: startSecond, duration, enemyGroups, eliteChance, rewardRule
~~~

性能预算建议：

| 对象 | 上限 | 策略 |
| --- | ---: | --- |
| 敌人 | 50–80 | 导演限制同屏生成 |
| 玩家子弹 | 120 | 对象池 |
| 敌方子弹 | 100 | 对象池 + 越界回收 |
| 粒子 | 200 | 超限合并或降级 |
| 伤害数字 | 20 | 合并同帧伤害 |

## 11. 路线图

### Phase 1：先让战斗好玩

- 深空霓虹 UI、激光/命中/爆炸反馈；
- 自动射击 + Dash；
- 三种敌人：侦察机、护卫舰、爆破虫；
- 经验晶体 + 三选一；
- 结算页 + 本地最高分。

验收：新玩家不看教程可完成一局；30 秒内至少升级一次；每局至少有一次明显火力成长。

### Phase 2：让每局不同

- 6–8 种武器/模块与标签协同；
- 精英敌人与风险门；
- 导演式波次；
- 更多主动技能；
- 无障碍与低性能模式。

验收：连续 5 局中，至少 3 局的核心构筑和高压时刻明显不同。

### Phase 3：Web Beta

- Flutter Web 构建、静态托管；
- 浏览器音频、生命周期和触屏输入；
- localStorage 设置与最高分；
- Web 性能测试、移动布局测试。

验收：打开链接 10 秒内开局；切换标签页不掉命；桌面与移动浏览器可完成一局。

### Phase 4：持续内容

Boss、敌人弹幕、特殊事件、每日挑战（本地 seed）、飞船外观、无尽模式。

## 12. 最小可行现代化版本

如果只做五件事，推荐优先级如下：

1. 自动射击 + Dash；
2. 经验晶体 + 三选一升级；
3. 三种行为不同的敌人；
4. 现代战斗反馈与结算页；
5. Web 构建、浏览器暂停和静态部署。

这五项完成后，Warship 会从技术演示小游戏升级为一个具备“再来一局”冲动的现代轻量射击游戏。

## 13. 明确不做

- 强制教程、复杂剧情、大量阅读；
- 账号、服务器、好友、付费设计；
- 十几个操作按钮；
- 纯数值堆叠、敌人只加速不加行为；
- 无预警秒杀；
- 十分钟后才出现高潮。
