# 图形交付目录说明

本说明为历史交付目录参考。正式资源请使用 [v2.0 素材清单与制作规范](../../03_素材/Warship_v2.0素材清单与制作规范.md) 与仓库根目录 `素材/manifest.json`；量产资产不得以本文件中的旧路径或旧 ID 命名为依据。

| 目录 | 应放入的资产 |
| --- | --- |
| `UI界面/HUD/` | `UI-HUD-*`：生命、护盾、经验、LV、连击、冲刺、暂停、Boss、预警遮罩等 |
| `UI界面/菜单与弹窗/` | `UI-HOME-*`、`UI-DRAFT-*`、`UI-RISK-*`、`UI-PAUSE-*`、`UI-RESULT-*` 和通用按钮/图标 |
| `角色与敌机/` | `gfx.player.*`、`gfx.enemy.*`、`gfx.elite.*`、`gfx.boss.*` 的基础机体和状态层 |
| `投射物与预警/` | `gfx.weapon.*`、`gfx.projectile.*`、`gfx.warning.*`、`gfx.pickup.*` |
| `战斗特效/` | `gfx.fx.*`、命中、爆炸、残骸、冲刺残影、护盾受击等独立特效层 |
| `场景背景/` | `gfx.bg.*`、战场网格、星云、远景和 Boss 入场背景层 |
| `概念样张/` | 仅供方向对齐，不得直接引用为最终运行时素材 |

交付人须在每次交付中附上源文件、导出文件、缩略预览、元数据和授权信息；状态与验收标准以 v2.0 素材清单与制作规范为准。
