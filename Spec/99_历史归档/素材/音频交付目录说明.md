# 音频交付目录说明

| 目录 | 用途 |
| --- | --- |
| `当前原型基线/` | 当前工程已有的原型 WAV，仅用于试听、临时集成和比较，不代表正式音频资产 |
| `待制作/` | 按 `sfx.*`、`bgm.*` Asset ID 交付的正式候选资产；通过响度、循环点、并发和授权验收后再进入运行时资源目录 |

正式交付须同时含母带、运行时文件和元数据。元数据至少包括 Asset ID、触发事件、总线、响度、峰值、最大并发、优先级、循环点、尾音、授权来源及版本；具体规格与验收以 [v2.0 素材清单与制作规范](../../03_素材/Warship_v2.0素材清单与制作规范.md) 为准。
