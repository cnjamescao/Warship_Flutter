## 1. 交付范围与禁止事项

- 本包覆盖 v2.1 新增的自动强化/自动风险结果徽记、清场提示、五种主弹道、玩家状态表现、敌人击毁、三档奖章及十三条运行时音效。
- 所有图形均为实际 PNG，所有音频均为实际 PCM WAV；没有空文件、同路径复用的占位文件或程序化正常态回退。
- 一线只能按下表的 Asset ID、文件、sheet 位置及接入约束编写 manifest；不得从文件名推断帧、不得自行把原 v2.0 占位图替代本包。
- 设计阶段的“可接入”仅指资源已具备；进入发布候选前必须满足本文件 §5 的人工验收门禁。

## 4. 技术接入契约

1. 新建 v2.1 manifest 条目时，`contentVersion` 固定为待发布的 v2.1 版本号；禁止覆盖 v2.0 已发布 ID。
2. 图形运行时加载完整 sheet 后，严格以 §2 的 `frameRect` 生成 sprite。渲染时保留透明像素，推荐 `screen/additive` 的 blendMode 仅用于效果层，奖章与 HUD 图标使用普通 alpha。
3. 每个图形 ID 还要在 manifest 写入本表 SHA-256。加载或 hash 校验失败时，测试/Release 必须报出 ID 与路径，不能悄悄切到占位资源。
4. 音频在运行时限制同一 cue 并发：玩家受击最多 2、Boss 命中 1、清场 1、奖章 1；高频受击应以 80ms 合并窗抑制爆音。v2.1 对局中 `PlayerDamaged` 只能路由 `SFX-V21-SHIELD-HIT` 或 `SFX-V21-HP-HIT` 之一，绝不能再同时路由 v2.0 同类 cue。
5. `SFX-V21-BOSS-HIT` 只绑定 `WeaponHit` 且 `targetIsBoss=true`，固定 `priority=90`、`maxVoices=1`、`minRetriggerMs=140`；通用 `SFX-EN-HIT` 只能绑定 `targetIsBoss=false`。Boss 命中 cue 启动时，AudioDirector 对命中/弹体 impact 子总线施加 `-6dB`、`110ms` 释放的短 duck，BGM 不 duck，确保独立反馈不被五种主弹道命中音掩盖。
6. 战斗中结果徽记不得烘焙文字，且 UI 不能在徽记旁加可见文案/框/按钮；仅无障碍 `Semantics`、暂停页和结算历史走本地化 key。
7. 同一完整 sheet 可服务多个 Asset ID，但只限于相同 SHA-256、相同 runtimeFile、每个 `frameRect` 均在 sheet 边界内且互不重叠。构建脚本必须只复制物理文件一次，以规范化的相对 runtime path 去重；不得以 basename 扁平化覆盖或复制 N 份 ID 副本。
